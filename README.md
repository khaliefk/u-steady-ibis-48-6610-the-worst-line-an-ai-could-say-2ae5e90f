One line, one bad idea: a machine that spots a human it cannot explain,
opens a review ticket on them, and then asks them to dinner.

## What it does

`main.py` (Python 3, stdlib only) writes a single pickup line to
`/output/entry.txt`. Nothing else runs, nothing is read from the network,
no secrets, no dependencies.

## Run it

```sh
python3 main.py
cat /output/entry.txt
```
